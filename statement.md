# Project Statement

## Problem Statement
Planning a trip manually can be difficult because trip information, expenses and daily activities are often maintained separately.

## Proposed Solution
Travel Planner is a simple Python desktop application that combines trip details, budget management and itinerary planning in one application.

## Scope
The application allows users to:
- Enter destination and trip dates
- Set number of travellers
- Set a travel budget
- Add and delete expenses
- Calculate remaining budget
- Create a daily itinerary
- Save information locally

## Target Users
Students, families and individual travellers.

## High-Level Features
- Trip management
- Budget tracking
- Itinerary management
- Input validation
- Local JSON data storage
